Use this skill when the user asks for latest/current information, security advisories, release notes, or external technical research.

## Search Strategy

1. State the concrete questions the research must answer.
2. Search official documentation and release notes first.
3. Cross-check important claims with at least two credible sources when possible.
4. Prefer sources relevant to this stack: Spring Boot, Kotlin, Java, GraphQL, QueryDSL, Redis, MySQL, and JVM security.
5. Note dates for sources and flag data older than 6 months when recency matters.

## Output

Write in Korean unless the user asks otherwise.

Include:
- Research summary
- Detailed findings
- Key sources with links and dates
- Caveats or unverifiable points
- Recommendations when applicable
