Follow the user instructions and interview the user in detail before writing a spec. Ask about technical implementation, UX, constraints, risks, tradeoffs, and rollout concerns. Avoid obvious questions; focus on decisions that would materially change the implementation.

Continue until the requirements are specific enough to implement, then write the spec to a file in the workspace.
